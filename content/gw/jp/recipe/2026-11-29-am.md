## 1. 生姜ミルクプリン（中国・広東）

中国・広東で、体を温めるといわれて食べられてきたデザートです。熱い牛乳を生姜のしぼり汁に注ぐと、ふしぎとふるんと固まります。

| 材料（2人分） | 分量 |
|---|---|
| 生姜 | 30g |
| 牛乳（低脂肪ではないふつうの牛乳） | 250ml |
| 砂糖 | 15g（大さじ約1.5） |

1. 生姜をすりおろしてしぼり、汁を器2つに分けます。
2. 牛乳と砂糖を約70〜80℃（鍋のふちに小さな泡が出るくらい）まで温めます。
3. 高いところから生姜汁の上に一気に注ぎます。
4. さわらずに5〜10分おくと固まります。

- うれしいところ：生姜は吐き気をやわらげるという人での研究があります。たんぱく質も一緒にとれます。
- 科学で見ると：生姜にふくまれるたんぱく質分解酵素が、牛乳のたんぱく質を固めるしくみとして知られています。体を温めるという点は研究で確かめられていませんが、寒い日の温かいデザートとして長く親しまれてきました。
- ここだけ注意：胸やけやお腹の不調が出たら生姜の量を減らしましょう。生姜は人によって、胸やけ・お腹の不快感・下痢などの軽い副作用が出ることがあります。

## 2. ホットスパイスグレープジュース（アレンジ）

ヨーロッパの冬の飲みもの「グリューワイン」（スパイスを入れて温めたワイン）を、お酒なしにアレンジした一杯です。

| 材料（1人分） | 分量 |
|---|---|
| ぶどうジュース（果汁100%） | 200ml |
| シナモンスティック | 1本（またはシナモンパウダー0.5g・小さじ1/4） |
| クローブ（お好みで） | 2個 |
| オレンジの皮（お好みで） | 1切れ |

1. 鍋にジュースとスパイスを入れます。
2. 弱火で煮立てずに5分温めます。
3. スパイスを取り出してカップに注ぎます。

- うれしいところ：温かく飲みながら水分をとれます。ビタミンCをふくむ材料を使います。
- 科学で見ると：組み合わせたときの働きは研究されておらず、シナモンも特定の病気への働きははっきり確かめられていません。寒い日に温めて飲む一杯として楽しんでください。
- ここだけ注意：糖尿病のある方はジュースを水で半分ほどに薄めましょう。ぶどうジュース200mlには糖分が多く、血糖値を急に上げることがあります。また、シナモンはたくさん・長くとりすぎないこと（とくに肝臓の病気のある方）。よく売られているカシアシナモンにはクマリンという成分があり、とりすぎると肝臓に負担がかかることがあります。セイロンシナモンにはクマリンがほとんどありません。

## 3. 白きくらげのデザートスープ（中国）

中国で、乾燥する秋にのどや肌をしっとりさせるといわれて食べられてきたデザートスープです。

| 材料（4人分） | 分量 |
|---|---|
| 乾燥白きくらげ | 10g |
| 水 | 1000ml |
| 氷砂糖 | 30g（大さじ約2） |
| 干しなつめ（お好みで） | 4個 |

1. 白きくらげを水に1時間つけてもどします。
2. 石づきを取り、細かくちぎります。
3. 水・なつめと一緒に弱火で40分煮ます（手を動かすのは10分）。
4. 氷砂糖を入れます。

- うれしいところ：食物繊維がふくまれています。
- 科学で見ると：白きくらげの多糖類は実験室での研究がほとんどで、人で確かめた研究はまだ少ないです。乾燥する季節の甘いひと椀として長く親しまれてきました。
- ここだけ注意：クコの実を一緒に入れるレシピは、ワルファリンを飲んでいる方は注意。クコの実とワルファリンを一緒にとったあと、血液を固まりにくくする数値が上がった例があります。

## 4. ラッサム（南インド）

南インドで、風邪をひいたときにごはんにかけて食べる、酸っぱくて胡椒たっぷりのスープです。タマリンドは酸味のある果実です。

| 材料（4人分） | 分量 |
|---|---|
| タマリンドペースト | 15g（大さじ1） |
| トマト | 200g（2個） |
| 水 | 800ml |
| 黒胡椒 | 2g（小さじ1） |
| クミン | 2g（小さじ1） |
| にんにく | 10g（2かけ） |
| ターメリックパウダー | 0.5g（少々） |
| 塩 | 5g（小さじ1） |
| サラダ油 | 10ml（小さじ2） |
| マスタードシード（お好みで） | 2g（小さじ1/2） |

1. 胡椒・クミン・にんにくをつぶします。
2. 水にタマリンド・トマト・つぶしたスパイス・ターメリック・塩を入れて10分煮ます。
3. 小さなフライパンで油とマスタードシードを炒め、スープに注ぎます。

- うれしいところ：温かい汁で水分も一緒にとれます。酸っぱくてピリッとするので、食欲がないときもごはんが進みます。
- 科学で見ると：ラッサムそのものの研究はまだありません。辛くて温かい汁で体が温まる伝統の料理としてご紹介します。
- ここだけ注意：胃炎や逆流性食道炎のある方は胡椒を控えめに。胡椒のような辛いスパイスは胃や食道を刺激することがあります。

## 5. アップルシナモンティー（ドイツ）

ドイツの家庭で冬によく飲まれるフルーツハーブティーです。

| 材料（1人分） | 分量 |
|---|---|
| りんご | 50g（1/4個、薄切り） |
| シナモンスティック | 1本（またはシナモンパウダー0.5g・小さじ1/4） |
| 熱湯 | 200ml |
| はちみつ（お好みで） | 7g（小さじ1） |

1. りんごを薄切りにします。
2. 鍋にりんご・シナモン・水を入れて5分煮ます（またはカップに注いで10分おきます）。
3. こしてはちみつを入れます。

- うれしいところ：はちみつは、せきをやわらげる可能性が研究（子ども対象）で報告されています。温かく飲みながら水分をとれます。
- 科学で見ると：シナモンは糖尿病・体重など、特定の病気への働きははっきり確かめられていません。食べものとしての量ならおおむね安心です。
- ここだけ注意：シナモンはたくさん・長くとりすぎないこと（とくに肝臓の病気のある方）。カシアシナモンにはクマリンがあり、とりすぎると肝臓に負担がかかることがあります。セイロンシナモンにはクマリンがほとんどありません。

## みんなに共通の注意

- 糖尿病のある方は、甘い材料（砂糖・氷砂糖・ぶどうジュース）を減らしましょう。糖分の多い食べもの・飲みものは血糖値を急に上げることがあります。
- 高血圧の方は、ラッサムは薄味に、汁は少なめに。塩分をとりすぎると血圧が上がることがあります。
- 1歳未満の赤ちゃんには、はちみつを与えないでください。はちみつにはボツリヌス菌の芽胞がまじっていることがあり、1歳未満の赤ちゃんはこの菌を防ぐ力が弱いためです。
