玉ねぎをじっくり炒めて甘みを出した、おうちのカレーです。にんにくと生姜を少し加えると、お店のような香りになります。

> 11月26日のおばあちゃんのレシピ動画「どうせ外で食べるなら」のコーナーで紹介したメニューです。外で食べても、時間のある日はおうちで作ってみてくださいね。

## 材料 (4人分)

| 材料 | 分量 |
|---|---|
| 豚こま切れ肉 | 300g |
| 玉ねぎ | 2個 |
| にんじん | 1本 |
| じゃがいも | 2個 |
| にんにく（すりおろし） | 1片 |
| 生姜（すりおろし） | 1片 |
| サラダ油 | 大さじ1 |
| 水 | 700ml |
| カレールウ | 1/2箱（約100g） |
| ご飯 | 4皿分 |

## 作り方

1. 玉ねぎは薄切り、にんじん・じゃがいもは一口大に切る。
2. 鍋にサラダ油を熱し、玉ねぎを中火で茶色くなるまで10分炒める。
3. にんにく・生姜と豚肉を加え、肉の色が変わるまで炒める。
4. にんじん・じゃがいもを加えて2分炒め、水700mlを注ぐ。
5. 煮立ったらアクを取り、弱火で野菜がやわらかくなるまで15分煮る。
6. 火を止めてルウを溶かし、再び弱火で混ぜながら5分煮込む。
7. ご飯に盛り付ける。

## おばあちゃんのコツ

- ルウは火を止めてから入れるとダマになりません。
- 一晩置くと味がなじんでさらにおいしくなります。
