焦がした生姜と玉ねぎ、シナモン・八角の香りがふわっと立つ、澄んだ牛肉スープのフォーです。煮込みは1時間以上かかりますが、手を動かすのは20分ほどです。

> 11月22日のおばあちゃんのレシピ動画「どうせ外で食べるなら」のコーナーで紹介したメニューです。外で食べても、時間のある日はおうちで作ってみてくださいね。

## 材料 (2人分)

| 材料 | 分量 |
|---|---|
| 牛すね肉（スープ用） | 300g |
| 牛肉しゃぶしゃぶ用（トッピング） | 100g |
| フォー（米麺） | 200g |
| 玉ねぎ | 1個 |
| 生姜 | 30g |
| シナモンスティック | 1本 |
| 八角 | 2個 |
| クローブ | 3粒 |
| 水 | 2L |
| ナンプラー | 大さじ3 |
| 砂糖 | 小さじ1 |
| 塩 | 少々 |
| もやし | 100g |
| 青ねぎ・パクチー・ライム | お好みで |

## 作り方

1. 玉ねぎと生姜は皮つきのまま半分に切り、油をひかないフライパンで表面が黒く焦げるまで焼く。
2. シナモン・八角・クローブをフライパンで1分からいりして香りを出す。
3. 牛すね肉は熱湯で5分下ゆでして洗う。
4. 鍋に水2L、牛すね肉、焼いた玉ねぎ・生姜、スパイスを入れて煮立て、弱火で1時間30分煮る。アクは取る。
5. スープをこし、ナンプラー大さじ3、砂糖小さじ1、塩で味を調える。すね肉は薄切りにする。
6. フォーはぬるま湯に30分つけてもどし、熱湯に20秒くぐらせて器に盛る。
7. すね肉・しゃぶしゃぶ用の肉・もやしをのせ、煮立てたスープを注いで肉に火を通す。青ねぎ・パクチー・ライムを添える。

## おばあちゃんのコツ

- 玉ねぎと生姜をしっかり焦がすと、スープの色と香りが深くなります。
- スープは多めに作って小分け冷凍しておくと、次は10分で一杯できます。
