紅茶とスパイスを小鍋で煮出し、牛乳を加えて仕上げるインド式のミルクティーです。5分でカフェの味になります。

> 11月24日のおばあちゃんのレシピ動画「どうせ外で食べるなら」のコーナーで紹介したメニューです。外で食べても、時間のある日はおうちで作ってみてくださいね。

## 材料 (2人分)

| 材料 | 分量 |
|---|---|
| 水 | 150ml |
| 紅茶の茶葉（アッサムなど） | 小さじ4（約8g） |
| 牛乳 | 300ml |
| 砂糖 | 大さじ1〜2 |
| シナモンスティック | 1本 |
| 生姜（薄切り） | 3枚 |
| クローブ | 3粒 |
| カルダモン（あれば） | 3粒 |

## 作り方

1. カルダモンは軽くつぶす。
2. 小鍋に水150mlとスパイス・生姜を入れて火にかけ、沸いたら弱火で2分煮る。
3. 茶葉を加えて1分煮出す。
4. 牛乳300mlと砂糖を加え、ふちがふつふつするまで温める（沸騰させない）。
5. 茶こしでこしてカップに注ぐ。

## おばあちゃんのコツ

- 牛乳を入れたら吹きこぼれやすいので目を離さないで。
- ティーバッグなら2〜3個で代用できます。
