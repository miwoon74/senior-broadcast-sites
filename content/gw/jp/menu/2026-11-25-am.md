秋のきのこをたっぷり入れて炊飯器で炊くだけ。だしとしょうゆの香りがふわっと広がるご飯です。

> 11月25日のおばあちゃんのレシピ動画「どうせ外で食べるなら」のコーナーで紹介したメニューです。外で食べても、時間のある日はおうちで作ってみてくださいね。

## 材料 (4人分)

| 材料 | 分量 |
|---|---|
| 米 | 2合 |
| しめじ | 1パック（100g） |
| しいたけ | 4枚 |
| まいたけ | 1パック（100g） |
| にんじん | 1/3本 |
| 油揚げ | 1枚 |
| しょうゆ | 大さじ2 |
| みりん | 大さじ2 |
| 酒 | 大さじ1 |
| 塩 | 小さじ1/4 |
| だし汁 | 適量 |

## 作り方

1. 米は洗ってざるにあげ、30分おく。
2. しめじ・まいたけはほぐし、しいたけは薄切り、にんじんは細切り、油揚げは油抜きして細切りにする。
3. 炊飯器に米と調味料を入れ、だし汁を2合の目盛りまで注いで軽く混ぜる。
4. 具をのせて（混ぜない）普通に炊く。
5. 炊き上がったら10分蒸らし、さっくり混ぜる。

## おばあちゃんのコツ

- 具は混ぜずにのせて炊くと炊きむらが出にくいです。
- おにぎりにしてもおいしいです。
