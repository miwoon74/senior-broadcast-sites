뽀얀 국물에 생강·계피·팔각 향이 은은하게 도는 소고기 쌀국수예요. 국물을 1시간 넘게 우려야 하지만, 손이 가는 시간은 20분 정도랍니다.

> 11월 22일 할머니 레시피 영상의 「어차피 사 먹을 텐데…」 코너에서 소개한 메뉴예요. 사 먹어도 좋고, 시간 나는 날엔 집에서 만들어 보세요.

## 재료 (2인분)

| 재료 | 분량 |
|---|---|
| 소고기 양지 (국물용) | 300g |
| 소고기 샤브샤브용 (고명) | 100g |
| 쌀국수 면 | 200g |
| 양파 | 1개 |
| 생강 | 30g (엄지 한 마디 크기 2개) |
| 통계피 | 1개 |
| 팔각 | 2개 |
| 정향 | 3개 |
| 물 | 2L |
| 피시소스 | 3큰술 |
| 설탕 | 1작은술 |
| 소금 | 약간 |
| 숙주 | 100g |
| 쪽파·고수·라임 | 취향껏 |

## 만드는 법

1. 양파와 생강은 껍질째 반으로 갈라 마른 팬에 겉이 까맣게 그을릴 때까지 굽는다.
2. 통계피·팔각·정향을 마른 팬에 1분 볶아 향을 낸다.
3. 양지는 끓는 물에 5분 데쳐 헹군다.
4. 냄비에 물 2L, 양지, 구운 양파·생강, 향신료를 넣고 끓으면 약불로 줄여 1시간 30분 끓인다. 위에 뜨는 거품은 걷어 낸다.
5. 국물을 체에 거르고 피시소스 3큰술, 설탕 1작은술, 소금으로 간한다. 양지는 얇게 썬다.
6. 쌀국수 면은 미지근한 물에 30분 불린 뒤 끓는 물에 20초 데쳐 그릇에 담는다.
7. 면 위에 양지, 얇은 생고기, 숙주를 올리고 펄펄 끓는 국물을 부어 고기를 익힌다. 쪽파·고수·라임을 곁들인다.

## 할머니 팁

- 양파와 생강을 까맣게 구워야 국물 색과 향이 깊어져요.
- 국물은 넉넉히 끓여 나눠 얼려 두면 다음엔 10분이면 한 그릇이에요.
