여러 버섯과 소고기를 냄비에 둘러 담고 맑은 육수를 부어 끓이는 전골이에요. 냄비째 식탁에 올려 끓이며 먹으면 겨울 저녁이 든든해요.

> 11월 25일 할머니 레시피 영상의 「어차피 사 먹을 텐데…」 코너에서 소개한 메뉴예요. 사 먹어도 좋고, 시간 나는 날엔 집에서 만들어 보세요.

## 재료 (2~3인분)

| 재료 | 분량 |
|---|---|
| 모둠 버섯 (표고·느타리·팽이·새송이) | 300g |
| 소고기 불고기용 | 150g |
| 양파 | 1/2개 |
| 대파 | 1대 |
| 멸치다시마 육수 | 800ml |
| 국간장 | 1큰술 |
| 다진 마늘 | 1큰술 |
| 소금 | 약간 |
| 고기 양념: 간장 | 1큰술 |
| 고기 양념: 설탕 | 1/2큰술 |
| 고기 양념: 참기름 | 1작은술 |

## 만드는 법

1. 소고기는 간장 1큰술, 설탕 1/2큰술, 참기름 1작은술에 10분 재운다.
2. 표고는 얇게, 새송이는 납작하게 썰고, 느타리와 팽이는 가닥을 나눈다. 양파는 채 썰고 대파는 어슷 썬다.
3. 전골냄비 바닥에 양파를 깔고 버섯과 고기를 색깔별로 둘러 담는다.
4. 육수 800ml에 국간장 1큰술과 다진 마늘 1큰술을 풀어 붓는다.
5. 센불에서 끓기 시작하면 중불로 줄여 고기가 익을 때까지 8~10분 끓이고 소금으로 간한다.
6. 대파를 올려 한소끔 더 끓인다.

## 할머니 팁

- 버섯은 물에 오래 담그지 말고 젖은 행주로 닦아요.
- 남은 국물에 칼국수 면이나 밥을 넣어 마무리해도 좋아요.
