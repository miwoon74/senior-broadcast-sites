清澈的牛肉高汤，散发着炭烤生姜、肉桂和八角的香气。高汤炖煮超过一个小时，但你亲自动手的时间大约是20分钟。

> 这是我们11月22日奶奶食谱视频中“外出就餐？”角落的菜肴。可以在餐馆享用，或者在有时间时在家制作。

## 材料（2人份）

| 材料 | 数量 |
|---|---|
| 牛腩（用于高汤） | 300克 |
| 薄切生牛肉（配料） | 100克 |
| 米粉 | 200克 |
| 洋葱 | 1个 |
| 新鲜生姜 | 30克 |
| 肉桂棒 | 1根 |
| 八角 | 2颗 |
| 丁香 | 3颗 |
| 水 | 2升 |
| 鱼露 | 3汤匙 |
| 糖 | 1茶匙 |
| 盐 | 适量 |
| 豆芽 | 100克 |
| 葱、香菜、青柠 | 供食用 |

## 步骤

1. 将洋葱和生姜（带皮）对半切开，在干锅中烤至变黑。
2. 在干锅中将肉桂、八角和丁香烘烤1分钟。
3. 将牛腩在沸水中焯水5分钟，然后冲洗。
4. 将2升水、牛腩、洋葱、生姜和香料放入锅中。煮沸后，轻轻炖煮1个半小时，撇去泡沫。
5. 过滤高汤，加入3汤匙鱼露、1茶匙糖和盐调味。将牛腩切薄。
6. 将米粉浸泡在温水中30分钟，放入沸水中焯水20秒，然后分装到碗中。
7. 在米粉上放上牛腩、生牛肉和豆芽，然后倒入沸腾的高汤以煮熟牛肉。配上葱、香菜和青柠一起享用。

## 奶奶的小贴士

- 烤洋葱和生姜可以让高汤呈现出深色和香气。
- 将多余的高汤分装冷冻，方便下次10分钟就能享用一碗。
