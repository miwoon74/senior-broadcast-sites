经典的双层苹果派。商店购买的饼皮让制作变得简单；馅料只需苹果、糖和肉桂。

> 这是我们11月23日奶奶食谱视频中“外出就餐？”角落的菜肴。可以在餐厅享用，或者在有时间时在家制作。

## 材料（8人份）

| 材料 | 数量 |
|---|---|
| 饼皮（商店购买，适用于双层苹果派） | 2 |
| 苹果 | 6个（约900克） |
| 糖 | 100克 |
| 肉桂粉 | 1茶匙 |
| 肉豆蔻粉 | 1/4茶匙 |
| 柠檬汁 | 1汤匙 |
| 玉米淀粉 | 2汤匙 |
| 黄油 | 2汤匙 |
| 鸡蛋（用于刷表面） | 1 |

## 步骤

1. 将烤箱预热至220°C。将一层饼皮放入9英寸的派盘中。
2. 将苹果去皮并切成1/4英寸厚的片。与糖、肉桂、肉豆蔻、柠檬汁和玉米淀粉混合。
3. 将苹果堆放在饼皮上，并点缀上黄油。
4. 用第二层饼皮覆盖，捏紧边缘并在顶部切4个小口。刷上打散的鸡蛋。
5. 烘烤20分钟，然后将温度降低至190°C，再烘烤35-40分钟，直到金黄且冒泡。
6. 切片前至少冷却2小时。

## 奶奶的小贴士

- 酸甜苹果的混合能带来最佳风味。
- 如果边缘上色过快，可以用铝箔覆盖。
