用酸奶腌制的鸡肉，配上奶油般的姜黄金色番茄酱。这是一道你可以在一个锅里制作的外卖最爱。

> 这是我们11月26日奶奶食谱视频中“外出就餐？”角落的菜肴。可以在餐馆享用，或者在有时间的时候在家制作。

## 材料（4人份）

| 材料 | 数量 |
|---|---|
| 去骨鸡腿肉 | 680克 |
| 原味酸奶 | 120克 |
| 姜黄粉 | 1.5茶匙 |
| 印度香料粉 | 3茶匙 |
| 孜然粉 | 1茶匙 |
| 辣椒粉 | 1茶匙 |
| 盐 | 1.5茶匙 |
| 黄油 | 2汤匙 |
| 洋葱，切碎 | 1个 |
| 大蒜，剁碎 | 3瓣 |
| 新鲜生姜，磨碎 | 1汤匙 |
| 番茄酱 | 1罐 400克 |
| 重奶油 | 120毫升 |

## 步骤

1. 将鸡肉切成小块。与酸奶、1茶匙姜黄、2茶匙印度香料粉、孜然、辣椒粉和1茶匙盐混合。腌制30分钟。
2. 在高温下烤或煎鸡肉，直到表面有焦痕。放置一旁。
3. 在锅中融化黄油，煮洋葱8分钟。加入大蒜和生姜煮1分钟。
4. 加入番茄酱、剩余的姜黄、印度香料粉和盐。炖煮10分钟。
5. 加入奶油和鸡肉，炖煮5分钟，直到鸡肉熟透。与米饭或印度饼一起享用。

## 奶奶的小贴士

- 鸡腿肉比鸡胸肉更嫩多汁。
- 如果想要酱汁更温和，可以不加辣椒粉。
