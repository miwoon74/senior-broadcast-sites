清澈的牛肉高湯，散發著炭烤薑、肉桂和八角的香氣。高湯煮超過一小時，但您親手準備的時間大約是20分鐘。

> 這道菜來自我們11月22日的「外食」角落的奶奶食譜影片。可以在餐廳享用，或在有時間的時候在家製作。

## 材料（2人份）

| 材料 | 數量 |
|---|---|
| 牛腩（用於高湯） | 300克 |
| 薄切生牛肉（配料） | 100克 |
| 米粉 | 200克 |
| 洋蔥 | 1 |
| 新鮮薑 | 30克 |
| 肉桂棒 | 1 |
| 八角 | 2 |
| 丁香 | 3 |
| 水 | 2公升 |
| 魚露 | 3湯匙 |
| 糖 | 1茶匙 |
| 鹽 | 適量 |
| 豆芽 | 100克 |
| 青蔥、香菜、檸檬 | 供應 |

## 步驟

1. 將洋蔥和薑（保留外皮）對半切開，放在乾鍋中烤至焦黑。
2. 在乾鍋中將肉桂、八角和丁香烘烤1分鐘。
3. 將牛腩在滾水中焯水5分鐘後沖洗。
4. 將2公升水、牛腩、洋蔥、薑和香料放入鍋中。煮沸後，輕輕煮1.5小時，撇去泡沫。
5. 過濾高湯，並加入3湯匙魚露、1茶匙糖和鹽調味。將牛腩切薄片。
6. 將米粉浸泡在溫水中30分鐘，然後在滾水中浸泡20秒，分裝到碗中。
7. 在米粉上放上牛腩、生牛肉和豆芽，然後倒入滾燙的高湯以煮熟牛肉。搭配青蔥、香菜和檸檬一起享用。

## 奶奶的小撇步

- 炭烤洋蔥和薑能讓高湯呈現深色和香氣。
- 將多餘的高湯分裝冷凍，方便下次10分鐘內就能享用一碗。
