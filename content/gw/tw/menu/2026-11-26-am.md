用優格醃製的雞肉，搭配奶油般的薑黃金色番茄醬。這是一道你可以在一個鍋中製作的外賣最愛。

> 這道菜來自我們11月26日的「外食」系列奶奶食譜影片。可以在餐廳享用，或在有時間時在家製作。

## 材料 (4人份)

| 材料 | 數量 |
|---|---|
| 去骨雞腿肉 | 680克 |
| 原味優格 | 120克 |
| 薑黃粉 | 1 1/2 茶匙 |
| 印度香料粉 | 3 茶匙 |
| 孜然粉 | 1 茶匙 |
| 辣椒粉 | 1 茶匙 |
| 鹽 | 1 1/2 茶匙 |
| 奶油 | 2 湯匙 |
| 洋蔥，切碎 | 1 |
| 大蒜，切末 | 3 瓣 |
| 新鮮薑，磨碎 | 1 湯匙 |
| 番茄醬 | 1 罐 400克 |
| 重奶油 | 120毫升 |

## 步驟

1. 將雞肉切成一口大小的塊。與優格、1茶匙薑黃、2茶匙印度香料粉、孜然、辣椒粉和1茶匙鹽混合。醃製30分鐘。
2. 在高火下將雞肉烤或煎至表面微焦。放置一旁。
3. 在鍋中融化奶油，將洋蔥煮8分鐘。加入大蒜和薑煮1分鐘。
4. 加入番茄醬、剩餘的薑黃、印度香料粉和鹽。小火煮10分鐘。
5. 加入奶油和雞肉，繼續小火煮5分鐘，直到雞肉熟透。可搭配米飯或印度餅享用。

## 奶奶的小貼士

- 雞腿肉比雞胸肉更嫩滑。
- 若想要醬汁更溫和，可以省略辣椒粉。
