經典的雙層酥皮蘋果派。使用市售酥皮讓製作變得簡單；餡料只需蘋果、糖和肉桂。

> 這道菜來自我們11月23日的奶奶食譜影片中的「外食」角落。可以在餐廳享用，或在有時間時在家製作。

## 材料（8人份）

| 材料 | 數量 |
|---|---|
| 市售酥皮（適用於雙層派） | 2 |
| 蘋果 | 6顆（約900克） |
| 糖 | 100克 |
| 肉桂粉 | 1茶匙 |
| 肉豆蔻粉 | 1/4茶匙 |
| 檸檬汁 | 1湯匙 |
| 玉米澱粉 | 2湯匙 |
| 奶油 | 2湯匙 |
| 蛋（用於刷表面） | 1顆 |

## 步驟

1. 將烤箱預熱至220°C。將一片酥皮放入9吋派盤中。
2. 將蘋果去皮並切成1/4吋厚的片。與糖、肉桂、肉豆蔻、檸檬汁和玉米澱粉拌勻。
3. 將蘋果堆放在酥皮上，並點綴上奶油。
4. 蓋上第二片酥皮，捏緊邊緣並在上面切4個小口。刷上打散的蛋液。
5. 烘烤20分鐘，然後將溫度降低至190°C，再烘烤35-40分鐘，直到表面金黃且冒泡。
6. 切片前至少冷卻2小時。

## 奶奶的小貼士

- 混合酸甜的蘋果能帶來最佳的風味。
- 如果邊緣上色過快，可以用鋁箔包住。
